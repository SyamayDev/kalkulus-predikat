Mengapa kita membutuhkan Kalkulus Predikat?

Logika Proposisi sangat penting, tetapi memiliki keterbatasan dasar. Kalkulus Predikat hadir untuk membedah struktur internal kalimat!

🔤

Logika Proposisi

Hanya menilai seluruh kalimat sebagai satu kesatuan utuh (Benar/Salah).

P = "Budi pintar"

⚠️ Kelemahan: Tidak bisa menganalisis hubungan variabel di dalam kalimat.

🔍

Kalkulus Predikat

Memecah kalimat menjadi objek/subjek (x) dan sifat/relasinya (Predikat).

P(x) = "x pintar"

✨ Kelebihan: Sangat detail dan powerful untuk sistem matematika & ilmu komputer!

📦

Kuantor Logika

Mengukur seberapa banyak objek yang memenuhi predikat tersebut.

∀ , ∃

🚀 Memungkinkan ekspresi pernyataan universal seperti "Semua..." atau "Ada...".

Konsep Dasar Predikat

Mengenal Variabel dan Fungsi Pernyataan

Apa itu Predikat?

Dalam logika, Predikat adalah pernyataan yang mengandung satu atau lebih variabel.

Predikat baru memiliki nilai kebenaran (True/False) JIKA variabelnya diganti dengan nilai tertentu.

⚡ Visual Predikat Tester Interaktif

P(4) → "4 Bilangan Genap" = TRUE

Semesta Pembicaraan (Domain)

Universe of Discourse

Nilai kebenaran suatu predikat sangat bergantung pada Domain (himpunan semua nilai yang mungkin untuk variabel).

Mengapa Domain Sangat Penting?

Pertimbangkan predikat: P(x) : x² > 0

Apakah pernyataan ini selalu BENAR? Jawabannya: Tergantung Domainnya!

Domain: Bilangan Bulat Positif

Jika x ∈ {1, 2, 3, ...}

1
2
3

P(x) selalu BENAR (TRUE)

Domain: Bilangan Bulat (Termasuk 0)

Jika x ∈ {..., -1, 0, 1, ...}

1
0
-1

P(0) bernilai SALAH (FALSE)

Negasi Kuantor

Hukum De Morgan untuk Kuantor Logika

Bagaimana cara membantah atau menegasikan pernyataan yang memiliki kuantor?

1. Negasi dari "Semua" adalah "Ada yang TIDAK"

¬(∀x P(x)) ≡ ∃x ¬P(x)

Pernyataan: "Semua mahasiswa hadir." ( ∀x H(x) )

Bantahan: "TIDAK semua mahasiswa hadir" ≡ "ADA mahasiswa yang TIDAK hadir." ( ∃x ¬H(x) )

2. Negasi dari "Ada" adalah "Semua TIDAK"

¬(∃x P(x)) ≡ ∀x ¬P(x)

Pernyataan: "Ada soal ujian yang sulit." ( ∃x S(x) )

Bantahan: "TIDAK ada soal ujian yang sulit" ≡ "SEMUA soal ujian TIDAK sulit." ( ∀x ¬S(x) )

Variabel Bebas & Terikat

Bound vs Free Variables

Variabel x dikatakan Terikat (Bound) jika diikat oleh kuantor ∀x atau ∃x.
Jika tidak diikat kuantor, maka ia adalah variabel Bebas (Free).

∀x P( x , y )

Variabel 'x'

TERIKAT (BOUND)

Karena berada langsung dalam cakupan kuantor ∀x

Variabel 'y'

BEBAS (FREE)

Karena tidak ada kuantor ∀y atau ∃y yang mengikatnya

Fungsi & Konstanta

Elemen Pelengkap dalam Predikat

Konstanta

P(x) = "x suka apel"
P(a) = "Budi suka apel"

Memetakan satu atau lebih objek ke objek lain dalam domain. Menghasilkan Objek (bukan True/False).

Evaluasi pada Domain Terbatas

Membuktikan Kuantor dengan Tabel Logika

Domain: D = { 1, 2, 3 }  |  Predikat: P(x) : "x > 0"

Nilai x P(x) : x > 0 Hasil
x = 1 1 > 0 True
x = 2 2 > 0 True
x = 3 3 > 0 True

∀x P(x) ≡ P(1) ∧ P(2) ∧ P(3)

True ∧ True ∧ True = TRUE

∃x P(x) ≡ P(1) ∨ P(2) ∨ P(3)

True ∨ True ∨ True = TRUE

Kuantor Bersarang (Nested)

Urutan Kuantor Sangat Menentukan Makna!

Misalkan: M(x) = Mahasiswa · D(y) = Dosen · B(x,y) = x dibimbing oleh y.

∀x ∃y B(x,y)

"Untuk setiap mahasiswa, ada dosen pembimbingnya."

Setiap mahasiswa punya dosen pembimbing masing-masing.

👨‍🎓→👨‍🏫   👩‍🎓→👩‍🏫
∃y ∀x B(x,y)

"Ada satu dosen yang membimbing SEMUA mahasiswa."

Hanya ada 1 dosen super yang membimbing seluruh mahasiswa.

Aturan Inferensi Predikat

Bagaimana Menarik Kesimpulan yang Sah?

1

Universal Instantiation (UI)

∀x P(x) → P(c)

Jika berlaku untuk semua elemen, maka pasti berlaku untuk elemen tertentu c.
Contoh: Semua manusia pasti mati. Socrates adalah manusia. Maka Socrates pasti mati.

2

Universal Generalization (UG)

P(c) sembarang → ∀x P(x)

Jika berlaku untuk elemen c yang dipilih sembarang, maka berlaku untuk semua elemen.

3

Existential Instantiation (EI)

∃x P(x) → P(c) untuk c tertentu

Jika ada setidaknya satu elemen yang memenuhi P, kita bisa menamainya dengan c.

4

Existential Generalization (EG)

P(c) tertentu → ∃x P(x)

Jika elemen c terbukti memenuhi P, maka terbukti bahwa ada elemen yang memenuhi P.

Translasi ke Logika Predikat

Mengubah Bahasa Alami Menjadi Notasi Matematika

Domain: Seluruh hewan · Predikat: K(x) = kucing, M(x) = mamalia.

∀x ( K(x) → M(x) )

📌 Kuantor Universal (∀) selalu dipasangkan dengan Implikasi (→).

Domain: Manusia · Predikat: M(x)=mahasiswa, R(x)=rajin, C(x)=cerdas.

∃x ( M(x) ∧ R(x) ∧ C(x) )

📌 Kuantor Eksistensial (∃) selalu dipasangkan dengan Konjungsi (AND / ∧).

Domain: Hewan · Predikat: B(x)=burung, R(x)=bisa berenang.

∀x ( B(x) → ¬R(x) )  ≡  ¬∃x ( B(x) ∧ R(x) )

Simulasi Kode Kuantor

Praktik Simpel & Eksekusi Langsung di Browser

Dalam pemrograman: every() mewakili ∀ (Universal), sedangkan some() mewakili ∃ (Eksistensial).

⚡ JavaScript Live Runner 
const domain = [1, 2, 3, 4, 5];

// Kuantor Universal ∀x (x > 0)
const semuaPositif = domain.every(x => x > 0);

// Kuantor Eksistensial ∃x (x === 3)
const adaAngkaTiga = domain.some(x => x === 3);
