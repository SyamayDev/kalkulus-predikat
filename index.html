Mengapa kita butuh Kalkulus Predikat?

Logika Proposisi sangat berguna, tetapi memiliki keterbatasan. Kalkulus Predikat hadir untuk mengatasi batasan tersebut dengan membedah isi dari sebuah pernyataan.

🔤

Logika Proposisi

Hanya melihat pernyataan sebagai satu kesatuan utuh (Benar/Salah).

P = "Budi pintar"

Kelemahan: Tidak bisa menganalisis bagian dalam kalimat.

🔍

Kalkulus Predikat

Memecah pernyataan menjadi objek (subjek) dan sifat/relasinya (predikat).

P(x) = "x pintar"

Kelebihan: Lebih detail, "Powerful" untuk matematika dan ilmu komputer.

📦

Kuantor

Mengukur "seberapa banyak" objek yang memenuhi predikat tersebut.

∀, ∃

Kelebihan: Memungkinkan pernyataan umum seperti "Semua..." atau "Ada...".

Konsep Dasar Predikat

Mengenal Variabel dan Fungsi Pernyataan

Apa itu Predikat?

Dalam tata bahasa, predikat memberi informasi tentang subjek. Dalam logika, predikat adalah pernyataan yang mengandung satu atau lebih variabel.

Predikat baru memiliki nilai kebenaran (True/False) JIKA variabel tersebut diganti dengan nilai spesifik.

Contoh 1: Satu Variabel

Monadik
P(x) : "x bilangan genap"
  • P(4) → "4 genap" Benar
  • P(5) → "5 genap" Salah

Contoh 2: Dua Variabel

Relasi
Q(x, y) : "x > y"
  • Q(5, 3) → "5 > 3" Benar
  • Q(2, 7) → "2 > 7" Salah

Semesta Pembicaraan (Domain)

Universe of Discourse

Nilai kebenaran suatu predikat sangat bergantung pada Domain (himpunan semua nilai yang mungkin untuk variabel).

Mengapa Domain Penting?

Pertimbangkan predikat P(x) : x² > 0

Apakah pernyataan ini selalu benar? Jawabannya: Tergantung Domainnya!

Domain: Bilangan Bulat Positif

Jika x ∈ {1, 2, 3, ...}

Maka P(x) selalu Benar, karena kuadrat bilangan bulat positif selalu > 0.

Domain: Bilangan Bulat

Jika x ∈ {..., -2, -1, 0, 1, 2, ...}

Maka P(x) bisa Salah! Karena jika x = 0, maka 0² > 0 adalah Salah.

Kuantor Universal (∀)

"Untuk Semua" / "Untuk Setiap"

∀x P(x)

Dibaca: "Untuk semua x, berlaku P(x)" atau "Setiap x memenuhi P(x)".

Contoh Kehidupan Nyata

P(x) = "x memiliki NIM"

Domain: Semua mahasiswa USU

∀x P(x)

Artinya: "Semua mahasiswa USU memiliki NIM."

Contoh Matematika

Q(x) = "x + 0 = x"

Domain: Bilangan Riil

∀x Q(x)

Artinya: "Untuk setiap bilangan riil x, x ditambah 0 sama dengan x."

Kuantor Eksistensial (&exists;)

"Terdapat" / "Ada setidaknya satu"

∃x P(x)

Dibaca: "Ada (setidaknya satu) x, sehingga berlaku P(x)".

Contoh Kehidupan Nyata

R(x) = "IPK x adalah 4.0"

Domain: Mahasiswa Fasilkom-TI

∃x R(x)

Artinya: "Ada (setidaknya satu) mahasiswa Fasilkom-TI yang IPK-nya 4.0."

Contoh Matematika

S(x) = "x² = 4"

Domain: Bilangan Bulat

∃x S(x)

Artinya: "Terdapat bilangan bulat x sedemikian rupa sehingga x² = 4." (Benar, karena ada x=2 atau x=-2)

Negasi Kuantor

Hukum De Morgan untuk Kuantor

Bagaimana cara menegasikan (membantah) pernyataan yang mengandung kuantor?

1. Negasi dari "Semua" adalah "Ada yang TIDAK"

¬(∀x P(x)) ≡ ∃x ¬P(x)

Pernyataan: "Semua mahasiswa hadir." ( ∀x H(x) )

Bantahan: "TIDAK semua mahasiswa hadir" ≡ "ADA mahasiswa yang TIDAK hadir." ( ∃x ¬H(x) )

2. Negasi dari "Ada" adalah "Semua TIDAK"

¬(∃x P(x)) ≡ ∀x ¬P(x)

Pernyataan: "Ada soal ujian yang sulit." ( ∃x S(x) )

Bantahan: "TIDAK ada soal ujian yang sulit" ≡ "SEMUA soal ujian TIDAK sulit (mudah)." ( ∀x ¬S(x) )

Variabel Bebas & Terikat

Bound vs Free Variables

Sebuah variabel x dikatakan terikat (bound) jika dikenai kuantor ∀x atau ∃x. Jika tidak, maka ia adalah variabel bebas (free).

∀x P( x , y )

Variabel 'x'

TERIKAT

Karena berada dalam cakupan kuantor ∀x

Variabel 'y'

BEBAS

Karena tidak ada kuantor ∀y atau ∃y yang mengikatnya

Catatan: Pernyataan hanya memiliki nilai kebenaran jika semua variabelnya terikat (atau diganti dengan konstanta).

Fungsi & Konstanta

Elemen Pelengkap dalam Predikat

📌

Konstanta

Objek spesifik/tertentu dari sebuah domain. Biasanya disimbolkan dengan huruf kecil awal alfabet (a, b, c) atau nama spesifik.

a = "Budi"

P(x) = "x suka apel"
P(a) = "Budi suka apel"

⚙️

Fungsi

Memetakan satu atau lebih objek ke objek lain dalam domain. Menghasilkan objek, BUKAN nilai kebenaran (True/False).

f(x) = "Ayah dari x"

Ayah(Budi) menghasilkan objek (misal: "Joko").
Tinggi(Ayah(Budi)) > 170.

Evaluasi pada Domain Terbatas

Membuktikan Kuantor dengan Tabel

Jika domain kita berhingga dan kecil, kita bisa mengekspansi kuantor menjadi operasi logika proposisi biasa (AND / OR).

Domain: D = { 1, 2, 3 }

Predikat: P(x) : "x > 0"

Nilai x P(x) : x > 0 Hasil
x = 1 1 > 0 True
x = 2 2 > 0 True
x = 3 3 > 0 True

∀x P(x) ≡ P(1) ∧ P(2) ∧ P(3)

T ∧ T ∧ T = True

∃x P(x) ≡ P(1) ∨ P(2) ∨ P(3)

T ∨ T ∨ T = True

Kuantor Bersarang (Nested)

Urutan Sangat Menentukan Makna!

Predikat sering kali memiliki lebih dari satu kuantor. Hati-hati: urutan kuantor yang berbeda tidak bisa ditukar sembarangan!

Misalkan: M(x) = Mahasiswa, D(y) = Dosen, B(x,y) = x dibimbing oleh y.

∀x ∃y B(x,y)

"Untuk setiap mahasiswa, ada (minimal satu) dosen pembimbing."

Setiap mahasiswa punya pembimbingnya masing-masing. (Bisa dosen yang berbeda untuk setiap mahasiswa).

👨‍🎓→👨‍🏫 👩‍🎓→👩‍🏫
∃y ∀x B(x,y)

"Ada satu dosen, yang membimbing SEMUA mahasiswa."

Hanya ada 1 dosen sakti yang menjadi pembimbing untuk seluruh mahasiswa di kampus.

Aturan Inferensi Predikat

Bagaimana menarik kesimpulan?

1

Universal Instantiation (UI)

∀x P(x) → P(c)

Jika sesuatu berlaku untuk semua elemen di domain, maka ia pasti berlaku untuk elemen tertentu c di domain tersebut.
Contoh: Semua manusia (x) pasti mati. Socrates (c) adalah manusia. Maka Socrates pasti mati.

2

Universal Generalization (UG)

P(c) sembarang → ∀x P(x)

Jika sesuatu berlaku untuk elemen c yang dipilih secara sembarang (tanpa asumsi khusus), maka ia berlaku untuk semua elemen.
Sering dipakai di pembuktian matematis "Ambil sembarang x..."

3

Existential Instantiation (EI)

∃x P(x) → P(c) untuk c tertentu

Jika ada setidaknya satu elemen yang memenuhi P, kita bisa menamainya dengan c (tapi kita tidak tahu c yang mana secara spesifik, yang jelas ia ada).

4

Existential Generalization (EG)

P(c) untuk c tertentu → ∃x P(x)

Jika kita tahu elemen c memenuhi P, maka terbukti bahwa ada elemen yang memenuhi P.

Penting: Untuk kuantor Universal (∀), kita menggunakan implikasi (→).

∃x ( M(x) ∧ R(x) ∧ C(x) )

Penting: Untuk kuantor Eksistensial (∃), kita menggunakan konjungsi (AND / ∧).

Predikat: B(x) = x burung, R(x) = x bisa berenang.

Bisa ditulis dengan dua cara yang ekuivalen:

∀x ( B(x) → ¬R(x) )

atauuu...

¬∃x ( B(x) ∧ R(x) )

Implementasi dengan JavaScript

Mempraktekkan Konsep di VS Code

Kalkulus Predikat adalah fondasi dari banyak fungsi array (High Order Functions) di pemrograman modern. every() merepresentasikan ∀, dan some() merepresentasikan ∃.

// === KALKULUS PREDIKAT DENGAN JAVASCRIPT ===

// 1. Definisi Domain (Semesta Pembicaraan)
const mahasiswa = [
  { nama: "Andi",  ipk: 3.8, semester: 4 },
  { nama: "Budi",  ipk: 3.2, semester: 6 },
  { nama: "Citra", ipk: 4.0, semester: 2 },
  { nama: "Dewi",  ipk: 2.9, semester: 8 },
  { nama: "Eka",   ipk: 3.5, semester: 4 },
];

// 2. Definisi Predikat (Fungsi yang return boolean)
const cumlaude    = (m) => m.ipk >= 3.5;
const lulusTepat  = (m) => m.semester <= 8;
const ipkSempurna = (m) => m.ipk === 4.0;

// 3. Kuantor Universal — ∀x P(x)
const semuaCumlaude = mahasiswa.every(cumlaude);
console.log("∀x Cumlaude(x):", semuaCumlaude);   // false

// 4. Kuantor Eksistensial — ∃x P(x)
const adaIpkSempurna = mahasiswa.some(ipkSempurna);
console.log("∃x IpkSempurna(x):", adaIpkSempurna); // true

// 5. Negasi Kuantor — ¬∀x P(x) ≡ ∃x ¬P(x)
const tidakSemuaCumlaude = mahasiswa.some(m => !cumlaude(m));
console.log("¬∀x Cumlaude ≡ ∃x ¬Cumlaude:", tidakSemuaCumlaude);

// 6. Universal Instantiation — ∀x P(x) → P(a)
const semuaLulusTepat = mahasiswa.every(lulusTepat);
if (semuaLulusTepat) {
  const andi = mahasiswa.find(m => m.nama === "Andi");
  console.log("UI - LulusTepat(Andi):", lulusTepat(andi));
}

Kesimpulan

Predikat & Domain

Predikat adalah pernyataan ber-variabel. Nilai kebenarannya sangat bergantung pada semesta/domain pembicaraan.

Kuantor

∀ (Universal) untuk menyatakan "Semua".
∃ (Eksistensial) untuk menyatakan "Ada/Beberapa".

Aplikasi

Sangat krusial untuk membuktikan teorema matematika dan implementasi logika pada bahasa pemrograman (array manipulation, database query).
